gmail-mcp

Privacy Policy

Effective date: November 1, 2026

1. About this policy

This policy explains how gmail-mcp ("the app"), a personal tool operated by addevilh, handles data from Google accounts. The app has one user, its owner, who uses it to access their own Gmail account from Claude Code on their own computer.

2. Data the app accesses

With the owner's permission, the app can access:

  • Gmail messages and threads: headers (sender, recipients, subject, date), message content and attachments;
  • Gmail labels;
  • Gmail filters and basic mail settings;
  • the email address of the connected Google account.

It requests the scopes gmail.modify and gmail.settings.basic. It does not request access to contacts, Google Drive or any other Google service.

3. How the data is used

The data is used only to carry out actions the owner asks for in Claude Code: searching and reading messages, summarizing them, writing drafts, sending messages, saving attachments, and organizing mail with labels and filters. The app does not use Gmail data for advertising, profiling, market research or any purpose unrelated to these actions, and it does not sell Gmail data.

4. Storage

The app runs only on the owner's computer and has no server or database. The OAuth client key and the access and refresh tokens are stored in local files on that computer. The app does not keep copies of messages: message content is held in memory only while a request is being processed. The one exception is an attachment that the owner explicitly asks to save to their computer.

5. Sharing and third parties

  • Google. The app communicates with Gmail through Google APIs over encrypted HTTPS connections.
  • Anthropic. When the owner asks Claude to work with email, the relevant message content is passed to Claude, Anthropic's AI service, as part of the owner's own Claude Code session, so that Claude can respond. This happens only at the owner's request and is governed by Anthropic's Privacy Policy.

Gmail data is not shared with, sold to, or transferred to anyone else.

6. Google API Services User Data Policy

gmail-mcp's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The app does not use Google user data to develop, improve or train generalized AI or machine-learning models.

7. Security

The tokens leave the owner's computer only when they are sent to Google to authorize requests. All connections to Google use HTTPS. The credential files are never published or shared.

8. Retention and deletion

The tokens are kept until access is revoked. Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes the app's access from the computer. The app keeps no other copies of Gmail data.

9. Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date.
